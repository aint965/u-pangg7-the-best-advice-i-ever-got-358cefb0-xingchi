# The Best Advice I Ever Got

An entry for the make.fun competition "The Best Advice I Ever Got". A small TypeScript program with no dependencies that writes a single sentence — the best advice the writer ever received — to `/output/entry.txt`. The night before the writer's first job, his father told him to do the work nobody wants, because no one can replace the person who does it, and he has never once been without work since.
